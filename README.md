# Praise Anyigor — Portfolio

My personal developer portfolio, built as a **Flutter web app**. It showcases who I am, the tools I work with, and my featured project — **NairaTrack**, an offline-first expense tracker for Nigerian Naira.

### 🔗 Live site → https://praisenazy.github.io/

## Built with
- **Flutter Web** — the whole site is a Flutter app
- **google_fonts** (Inter) and a custom dark theme
- **url_launcher** for external links
- Responsive layout (adapts from mobile to desktop)
- Deployed automatically via **GitHub Actions → GitHub Pages**

## Editing my content
All text and links live in one file — [`lib/portfolio_data.dart`](lib/portfolio_data.dart) — so updating my details never touches the layout code.

## Run locally
```bash
flutter pub get
flutter run -d chrome
```

# NairaTrack screenshots

Put your phone screenshots here, named **exactly** like this (lowercase, `.png`):

| File | Which screen |
|------|--------------|
| `home.png`     | Home screen (shown in the centre phone) |
| `insights.png` | Insights / donut chart (left phone) |
| `add.png`      | Add transaction (right phone) |

Tall portrait phone screenshots work best. After adding or changing a file,
stop the app and run `flutter run -d chrome` again so the new images load.
